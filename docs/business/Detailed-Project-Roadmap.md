# BLONG MVP: Detailed Project Roadmap

## 1. Estimated Timeline & Resources
- **Total Estimated Time-to-Launch:** **15 to 18 months**.
- **Reasoning:** The comprehensive, feature-rich scope of all three phases requires a significant investment in quality development, design, and testing.
- **Core Team Required:**
    - 1 Project Manager
    - 1 UI/UX Designer
    - 1 DevOps Engineer
    - 1 ML Engineer
    - 6-7 Developers (mix of Backend and Frontend)

## 2. Stage 1: Foundation & Planning (Months 1-4)
- **Objective:** To prepare the team, funding, and technical groundwork for development.
- **Key Activities:**
    - Secure project budget.
    - Recruit the full core team.
    - Select cloud provider and finalize all tooling.
    - Conduct detailed UI/UX design sprints to produce high-fidelity mockups for all screens.
    - Create a detailed project backlog by writing user stories for every feature in the scope document.
- **Deliverables:** A complete UI/UX design in Figma; a project backlog in a tool like Jira; a fully onboarded team.

## 3. Stage 2: Core Infrastructure & Phase 1 Development (Months 5-10)
- **Objective:** To build the core technical infrastructure and the complete "Singles" phase experience.
- **Key Activities:**
    - DevOps engineer sets up the Kubernetes cluster, databases, and CI/CD pipelines.
    - Backend team builds the core services (Auth, User, Relationship, Notification).
    - ML Engineer develops and trains the first version of the matching model.
    - Frontend and Backend teams collaborate to build all features of the "Singles" phase.
- **Milestone:** A fully functional "Singles" phase ready for internal testing.

## 4. Stage 3: Phase 2 & 3 Development (Months 11-16)
- **Objective:** To build the complete "Engagement" and "Wedding Prep" experiences.
- **Key Activities:**
    - Backend team builds the `engagement-service` and `wedding-prep-service`.
    * Frontend team builds all screens and functionality for the planning and wedding prep phases, including the culturally specific tools.
    - Heavy focus on integration testing to ensure all parts of the app work together seamlessly.
- **Milestone:** A feature-complete application containing all three phases.

## 5. Stage 4: Beta Testing & Launch (Months 17-18)
- **Objective:** To conduct final testing, fix bugs, and launch the application to the public.
- **Key Activities:**
    - Conduct a closed beta test with a select group of users to gather feedback.
    - Perform security audits and performance optimization.
    - Prepare app store listings for iOS and Android.
    - Publicly launch the BLONG MVP.
- **Deliverables:** The live application on the App Store and Google Play.
